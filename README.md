# 帧序工坊 · FGL Frame Studio

一个在浏览器本地运行的序列帧工具：导入图片或文件夹，调整方向、缩放与间距，预览动画并导出透明 PNG 长图。

## 使用

线上地址：https://future-game-laboratory.github.io/2D-Frame-Studio/

- 选择图片、选择文件夹，或把素材拖到导入区。文件按自然数字顺序排列。
- 调整横向 / 竖向、输出缩放和像素间距。尺寸实时更新。
- 切换“动画预览”调整 FPS、循环播放或逐帧检查；展开帧列表可定位任意已展示帧。
- 点击“导出 PNG”。所有帧都用于导出，保留透明背景。
- 没有素材时，可以点击“试用示例”体验完整流程。

图片只在浏览器内存中处理，没有上传接口、统计脚本或外部运行时依赖。刷新页面会清空素材。动画格式按单个静态帧读取，不拆解 GIF 动画。

## 开发

使用 Node.js 22 或更高版本，无需安装 npm 依赖。

```sh
npm start
# http://127.0.0.1:8765
npm test
```

请使用 HTTP 服务打开页面，避免 file:// 对 ES modules 的限制。

## 结构

- `index.html`：语义化页面、导入和预览控件。
- `src/styles.css`：统一的 FGL 黑白配色、响应式布局和交互状态。
- `src/app.js`：应用状态、事件、预览、播放和导出协调。
- `src/composite.js`：不依赖 DOM 的尺寸、对齐、位置与安全缩放计算。
- `src/files.js`：图片解码、文件排序、文件夹遍历及资源释放。
- `src/utils.js`：数值约束、尺寸适配和格式化。
- `tests/composite.test.js`：混合尺寸、纵向布局、缩放、超限、排序测试。
- `scripts/serve.js`：无依赖的本地开发服务器，仅监听 127.0.0.1。

## 性能与边界

预览直接按缩略尺寸绘制原始帧；完整输出画布只在下载时分配，下载结束后立即缩回 1×1。动画切帧只更新画布和前后选中行，不重建帧列表；修改 FPS 不重算拼接图。页面转到后台时暂停播放。

导出边长限制为 32,767 px，总面积为 67,108,864 px（仅 RGBA 导出表面约 256 MiB，原图还会占用额外内存）。这些是应用保护阈值，不保证每台设备都能成功分配；实际失败会提示减小缩放。超限素材仍可预览，可使用自动缩小按钮。帧列表展示前 180 帧，预览滑块、播放和导出使用全部帧。

导入采用原子替换：新素材全部解码成功才替换旧素材，失败会释放新资源并保留原序列。加载和导出期间禁用冲突操作。

## 部署

GitHub Pages 从 `main` 分支根目录部署，无构建步骤。保留 `.nojekyll`，所有资源引用采用相对路径以支持项目子路径。更新代码后推送 `main` 即可发布。浏览器可能缓存页面约 10 分钟，可用 Ctrl+F5 或给网址附加版本查询参数。

## 手工回归

1. 导入混合尺寸图片；核对自然排序、透明间距及居中。
2. 切换方向，修改缩放与间距，检查显示尺寸和实际 PNG。
3. 动画播放 / 暂停、循环开关、FPS、逐帧、滑块、帧列表跳转。
4. 导入损坏图片，确认已有序列保留；清空后检查初始状态。
5. 桌面及 390px 手机宽度检查溢出、按钮、Tab 键焦点。
